# Development vision

Canonical product vision: [../VISION.md](../VISION.md).

This package is a thin CLI over `@winccoa-tools-pack/npm-winccoa-core` for:

- installed WinCC OA **versions** (+ paths)
- **registered projects** as JSON (runnable, path, version, …)

Do not reimplement discovery here. Prefer core for in-process Node usage.
